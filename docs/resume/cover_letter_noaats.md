## 1. 자신만의 특별함 (성장과정, 학교생활/경력내용, 가치관)

**'Deep Dive & Wide View'가 저의 성장 철학입니다.**

강남대학교 소프트웨어응용학부에서 4학기 연속 학부 수석(GPA 4.24/4.5)을 유지하며 이론적 기반을 다졌고, 동시에 **금융 도메인 프로젝트**를 통해 실무 역량을 쌓았습니다.

**Cortex 프로젝트**를 통해 개인 투자자를 위한 퀀트 플랫폼을 독자적으로 설계·구현했습니다. 단순한 CRUD API가 아닌, **'실시간 금융 연산을 안정적으로 처리하면서 수백만 건의 시계열 데이터를 밀리초 단위로 조회'**하는 것이 핵심 과제였습니다. 이 과정에서 GRU/LSTM 기반 AI 예측 모델 학습 파이프라인, ONNX 추론 시스템, CPU/IO 워커 분리, 베이지안 최적화, 복식부기 크레딧 시스템 등 **엔터프라이즈급 아키텍처**를 적용했습니다.

저는 기술이 **복잡한 금융 로직을 시스템에 녹여낼 때** 비로소 가치가 있다고 믿습니다. 그래서 단순히 코드를 작성하는 것을 넘어, 비즈니스 목표를 이해하고 **최적의 아키텍처를 설계하는 제너럴리스트**를 지향합니다.

## 2. 자신의 강점과 단점

### [강점: AI를 유능한 부사수처럼 다루는 프롬프트 엔지니어링 역량]

**AI를 단순한 도구가 아닌, 개발 파트너로 활용하는 것이 저의 핵심 강점입니다.** Google Antigravity와 MCP 도구(Context7, Sequential Thinking, TestSprite)를 연동하여 **문서 검색→분석→테스트 자동화 워크플로우**를 구축했습니다. 21st.dev 같은 AI 디자인 스튜디오로 UI를 신속하게 프로토타이핑한 후 코드로 구현하는 **Vibe Coding 프로세스**를 확립했습니다.

Cortex 프로젝트에서는 사용자가 직접 AI 모델을 학습하고 배포하는 **No-Code 인터페이스**를 설계했습니다. AI의 '사용자'이자 AI 서비스의 '구현자'로서 **양면의 경험**을 갖추고 있습니다.

### [단점: 완벽주의로 인한 일정 지연]

초기에는 완벽한 코드를 추구하느라 일정을 지연시킨 적이 있습니다. 이를 극복하기 위해 **'API-First 개발 방식'**을 도입했습니다. MVP를 빠르게 출시한 후 사용자 피드백을 반영하여 개선하는 방식으로 전환하였고, **하루 만에 핵심 기능을 완성하는 속도와 품질의 균형**을 찾았습니다. 완벽한 계획보다 **빠른 프로토타이핑과 개선(Iterative Process)**을 즐기는 방식으로 변화했습니다.

## 3. 차별화된 방식으로 성공적인 결과를 얻은 경험

### Cortex 프로젝트: 벡터 연산으로 백테스팅 98% 성능 향상

- **[기존 방식]** Python For 루프로 수십만 개의 캔들(OHLCV) 데이터를 순회하며 지표 계산 시 **수 분이 소요**되었습니다. 사용자가 백테스트 버튼 클릭 후 멍하니 기다려야 하는 **최악의 UX**였습니다.

- **[차별화된 시도]** 모든 연산을 **NumPy/Pandas 벡터 연산**으로 전환했습니다. `np.where`로 조건문을 벡터화하고, 컬럼 단위 일괄 처리로 루프를 완전히 제거했습니다.

  ```python
  # For 루프 대신 벡터 연산
  df['signal'] = np.where(
      (df['sma_short'] > df['sma_long']) &
      (df['sma_short'].shift(1) <= df['sma_long'].shift(1)),
      1,  # 골든크로스: 매수
      np.where(df['sma_short'] < df['sma_long'], -1, 0)
  )
  ```

- **[진행과정]** **Generator 기반 Step-by-Step 실행**으로 Optuna 중간 Pruning을 가능하게 했습니다. WFO 10-Fold × 100 Trial = 1000회 실행 중 하위 50%를 중간에 중단하여 연산 시간을 1/5로 단축했습니다.

- **[결과]** 1년 치 백테스팅 **45초→0.8초로 98% 단축**. 사용자가 '실시간'으로 여러 전략을 비교할 수 있는 경험을 제공했습니다.

## 4. 가장 어려웠던 경험과 극복, 배운점

### CPU-bound vs I/O-bound 워커 분리: 물리적 격리의 필요성

- **[어려웠던 경험]** 초기에는 백테스팅을 FastAPI 엔드포인트 내부에서 직접 실행했습니다. **Pandas 연산이 CPU를 점유하자 async 이벤트 루프가 멈춰버려**, 헬스 체크를 포함한 모든 API 요청이 타임아웃되었습니다. 로드밸런서가 서버를 '죽은 것'으로 판단하여 트래픽을 차단하는 **치명적 장애**가 발생했습니다.

- **[극복 노력]** 아키텍처를 **근본적으로 변경**했습니다. Celery를 도입하여 연산 작업을 별도 프로세스로 위임(Fire-and-Forget)하고, FastAPI는 '요청 접수 → 작업 ID 반환 → 진행률 조회'만 담당하도록 역할을 분리했습니다. **`cpu_bound_queue`(prefork Pool)와 `io_bound_queue`(gevent Pool)로 워커를 물리적으로 분리**하여, 백테스팅 진행 중에도 매매 주문은 밀리초 단위 즉시 체결을 보장했습니다.

- **[배운점]** `async/await`는 I/O 대기를 효율화할 뿐, **CPU를 점유하는 연산은 결국 이벤트 루프를 블로킹**한다는 것을 깨달았습니다. 논리적 분리(Queue)가 아닌 **물리적 분리(별도 컨테이너)**해야 진정한 격리가 가능함을 배웠습니다. 금융 시스템에서 **데이터 정합성과 실시간 처리는 타협 불가**라는 원칙을 체득했습니다.

## 5. 지원 직무 차별화 역량과 노력

### [차별화 역량: 복잡한 금융 로직을 시스템에 녹여내는 No-Code AI 플랫폼 구현 경험]

**비개발자도 AI 모델을 학습하고 투자 전략을 설계할 수 있는 플랫폼**을 구현한 경험이 저의 차별화 역량입니다. 현재 이 기술을 **특허출원 진행 중**입니다.

> **특허 핵심**: 인공지능 학습 모델을 이용하여 **노코드 환경에서 복합 투자 전략을 구성**하고, 모델의 예측값과 불확실성을 **이중 모드 평가 엔진**을 통해 직관적인 매매 신호로 변환하는 기술

### [갖추기 위한 노력]

1. **AI 로직 블록 시스템 설계 (특허출원 중)**: AI 모델의 메타데이터(입력 형태, 출력 타입)를 분석하여 표준화된 인터페이스의 로직 블록으로 변환하고, 분류(Classification)와 회귀(Regression) 모델을 하나의 시스템에서 통합 처리하는 **이중 모드 신호 평가 엔진**을 구현했습니다.

2. **금융 알고리즘 시스템 구현**: Triple Barrier 라벨링(Marcos López de Prado의 금융 ML 표준 방법론), GRU/LSTM 시계열 예측, Optuna TPE 베이지안 최적화를 직접 구현했습니다.

3. **대용량 시계열 데이터 처리**: TimescaleDB Hypertables로 수억 건의 OHLCV 데이터를 자동 청크 파티셔닝하고, (ticker, time DESC) 복합 인덱스로 조회 성능을 최적화했습니다.

4. **복식부기 크레딧 시스템**: 금융 감사(Audit)를 위한 Ledger(생성)/Transaction(소비) 분리, 우선순위 FIFO 알고리즘을 구현하여 완전한 추적성을 확보했습니다.

5. **AI Tool 활용 역량**: Gemini, Claude, Copilot을 활용한 개발은 물론, MCP 서버 연동 자동화 워크플로우 구축 경험이 있습니다.

노아에이티에스가 **요구사항 정의부터 배포까지 전 과정에 AI(LLM) 기반의 '바이브코딩' 방법론**을 도입하고 있다는 점이 저의 개발 철학과 완벽히 일치합니다.

특히 **자산운용 시스템 전문 기업**이라는 점이 매력적입니다. Cortex 프로젝트에서 **퀀트 투자 플랫폼**을 독자적으로 설계·구현한 경험이 있어, 금융 도메인에 대한 이해와 프론트-미들-백오피스를 아우르는 시스템 연동 경험을 즉시 적용할 수 있습니다.

1. **AI Tool 활용 역량**: MCP 도구 연동, 프롬프트 엔지니어링, AI 코드 검증 경험을 바로 실무에 적용하여 개발 생산성을 높이겠습니다.

2. **금융 시스템 개발 경험 직접 활용**: 시계열 데이터 처리(TimescaleDB), 복식부기 시스템, 백테스팅 엔진 등 Cortex에서 구현한 금융 로직을 노아에이티에스의 자산운용 시스템에 즉시 기여하겠습니다.

3. **빠른 프로토타이핑과 개선**: API-First 개발 방식과 Iterative Process를 통해 MVP를 빠르게 출시하고 지속적으로 개선하는 문화에 적극 참여하겠습니다.

## 7. 자유양식

### 질문: 복잡한 금융 로직을 시스템에 녹여낸 구체적 사례

**Cortex 프로젝트에서 구현한 핵심 금융 로직:**

#### 1) Triple Barrier 라벨링 (금융 ML 표준 방법론)

단순 'Up/Down' 라벨링은 가격 잡음에 민감하고 실제 P&L과 연결되지 않습니다. **Take Profit(+2%), Stop Loss(-1%), Time Horizon(24시간)** 세 장벽 중 먼저 도달하는 것으로 라벨을 결정하여, 모델이 실제 트레이딩 시나리오와 연관된 패턴을 학습하도록 했습니다.

#### 2) 고급 데이터 시각화 및 분석 대시보드

백테스팅과 WFO(Walk-Forward Optimization) 결과를 **다양한 차트와 그래프로 시각화**했습니다. 수익 곡선, Drawdown 차트는 물론, 수천 건의 Trial 데이터를 **Parallel Coordinates Plot(평행좌표 플롯)**으로 표현하여 파라미터 간 상관관계를 직관적으로 파악할 수 있게 했습니다. Optuna의 **fANOVA 알고리즘**으로 수익률에 가장 큰 영향을 미친 파라미터를 정량적으로 추출하여 API로 제공합니다.

#### 3) 복식부기 크레딧 시스템

단순 `balance -= amount`는 추적 불가. **CreditLedger(원장)와 CreditTransaction(소비 기록) 분리**, CreditTransactionDetail로 어떤 원장에서 얼마가 차감되었는지 추적하여 **환불/감사 시 완전한 근거 자료**를 제공합니다.

# 포트폴리오 최신화·구조 개선 검증 — 2026-09-26

## 변경 범위

한국어·영어 프로필에 Codex·Claude Code 개발 경험, ‘느린 뇌, 빠른 손’, Jev 디자인 프로그램을 반영했다. 디자인 프로그램은 구현 중으로 표시하고, 투자 성과나 전 구간 실전 검증 완료를 주장하지 않는다. 개인정보·학력·경력·논문 데이터와 과거 회사별 지원서는 보존했다.

사용자 후속 요청에 따라 Processing Games와 해당 프로젝트에만 연결된 Processing·Arduino 노드를 제거했다. Cortex 프론트엔드·백엔드는 AI/ML 카테고리의 `project-cortex` 하나로 통합하고, 주요 프로젝트 목록과 모든 기술 연결을 갱신했다. 기존 기능 상세 15개와 코드 예시 21개, 저장소·배포 링크를 유지했다. 최종 데이터는 언어별 36개 노드·7개 프로젝트이며 `npm test`와 빌드로 재검증했다.

모달의 조립·탭 정의·본문 표현·입력 수명을 분리하고, 검색/정렬과 3D 배치 계산을 UI 밖으로 옮겼다. 구조 정본은 [아키텍처](ARCHITECTURE.md#책임과-의존-방향-2026-09-26), 모달 사용 계약은 [컴포넌트 문서](COMPONENTS.md#modaltsx와-modal)를 따른다.

## 성능·화면 개선 결과

- 소개와 최근 프로젝트 3개를 HTML로 즉시 표시하고, 기존 최소 2.5초 대기 + 1.2초 종료 애니메이션의 전체 화면 차단을 제거했다.
- `Scene`은 별도 청크로 불러오고, `Modal`·문의 폼은 열 때 불러온다. EmailJS는 실제 제출 시 불러온다. 기능별 오류 경계가 HTML 탐색을 유지한다.
- 필터/BFS 계산은 좌표와 분리되어 드래그마다 재실행되지 않는다. ID 인덱스 조회와 연결 중복 제거, 필요한 상태만 구독, 노드/연결 메모이제이션을 적용했다.
- 노드 크기 보간용 프레임별 Vector3 생성 2개를 재사용으로 바꾸고, 드래그 중 연결선 shader/material/Object3D를 유지한다. geometry·이벤트·지연 작업은 소유자가 정리한다.
- 텍스트 색상, 키보드 포커스, 접힌 패널의 `inert`, 모바일 소개와 시스템 움직임 감소 설정 대응을 개선했다.

동일 프로젝트에서 콘텐츠 정리 후 성능 작업 직전 빌드와 비교했다. 단위는 Vite 출력의 kB다.

| 산출물 | 개선 전 | 개선 후 |
|---|---:|---:|
| HTML이 직접 참조하는 주 JS | 1,850.64 | 574.43 |
| 주 JS gzip | 548.18 | 187.79 |
| 별도 3D 청크 | 주 JS에 포함 | 1,017.47 (gzip 278.13) |
| 상세 화면 청크 | 주 JS에 포함 | 181.15 (gzip 51.36) |

주 JS 파일은 약 69% 감소했다. 3D 청크는 진입 후 불러오므로 이 비율은 **페이지 전체 다운로드량·로드 시간·FPS 감소율이 아니다**. 네트워크 지연, 실기기 FPS와 장시간 메모리 벤치는 측정하지 않았다.

## 리뷰와 남은 경고

독립 코드 리뷰 **PASS**. 단일 책임, 표현과 상태/계산의 의존 분리, 좁은 props와 함수형 합성, 그래프 의미 보존과 자원 수명을 확인했다. 발견한 모달 이동·지연 로딩·SVG 복귀 포커스 문제는 수정했다.

주 JS와 3D 청크의 500kB 초과 경고는 남아 있다. 양 언어 상세 데이터는 동기 조회 계약으로 유지한다. 설치된 `postprocessing`과 `three`의 기존 peer 범위 경고도 남아 있으며, 이번 작업에서 라이브러리·잠금 버전은 변경하지 않았다. 구현 검증 단계에서는 커밋·푸시·배포를 실행하지 않았다. 이후 사용자 요청으로 수행한 배포는 아래 기록을 따른다.
